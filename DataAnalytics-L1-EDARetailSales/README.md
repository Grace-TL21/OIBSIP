# Exploratory Data Analysis on Retail Sales Data

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales trends, customer behavior, product performance, and business insights.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains information such as:

- Customer ID
- Gender
- Region
- Age
- Product Name
- Category
- Unit Price
- Quantity
- Total Price
- Shipping Fee
- Shipping Status
- Order Date

## Analysis Performed

- Data inspection and cleaning
- Descriptive statistics
- Monthly sales analysis
- Quarterly sales analysis
- Customer demographic analysis
- Product category analysis
- Top-selling products
- Correlation analysis
- Additional visualizations
- Business recommendations

## Conclusion

The analysis helps identify important sales patterns and customer behavior that can support better business decisions.
